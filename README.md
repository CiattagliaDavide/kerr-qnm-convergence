# Convergence of the quasinormal-mode expansion of the Kerr Green function

`Kerr_QNM.nb` contains the Mathematica calculation and its saved results. The computed poles, profiles and CSV tables are in `data/`. The nine paper figures are in `figures/`.

In Mathematica, set `compute = False` to use the saved data, or `True` to calculate missing data. Existing files are reused. Results are written to `data/` beside the notebook.

For Overleaf, upload the PDFs in `figures/`. The notebook and data accompany the article.
